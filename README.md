# Library Management System

## 1. Introduction

The Library Management System is a web-based application developed to help librarians manage library activities easily. The system provides a simple way to manage books, authors, categories, library members and borrowing records.

It is designed to reduce manual record keeping, improve accuracy and make library operations more organised.

## 2. Project Objectives

- To develop a system for managing library books.
- To keep records of authors and book categories.
- To register and manage library members.
- To record book borrowing and returning activities.
- To monitor overdue books.
- To provide secure login for librarians.
- To make library information easier to access and manage.

## 3. Technologies Used

The following technologies were used to develop the system:

- HTML – for webpage structure.
- CSS – for webpage styling and layout.
- JavaScript – for basic webpage interactions.
- PHP – for server-side programming.
- MySQL – for database management.
- XAMPP – for running the local web server and database.
- Visual Studio Code – for writing and editing code.
- Git and GitHub – for version control and project collaboration.

## 4. System Features

The Library Management System includes the following features:

### User Authentication
- Librarian login.
- Secure password verification.
- Logout functionality.
- Session-based access protection.

### Book Management
- Add new books.
- View registered books.
- Edit book information.
- Delete book records.

### Author Management
- Add authors.
- View author records.
- Edit author details.
- Delete authors.

### Category Management
- Add book categories.
- View categories.
- Edit category information.
- Delete categories.

### Member Management
- Register new members.
- View member records.
- Edit member information.
- Delete member records.
- Manage active and suspended members.

### Loan Management
- Issue books to members.
- Record book returns.
- Calculate book return dates.
- Monitor overdue books.
- Update available book copies.

### Dashboard
The dashboard provides an overview of library activities, including:
- Total books.
- Total members.
- Total loans.
- Borrowed books.
- Overdue books.

## Library Statistics and Reports

The Library Management System is intended to provide a statistics and reports section where the librarian can monitor library activities and access important information.

### Statistics to be displayed

- **Total Books:** Shows the total number of books registered in the library.
- **Available Books:** Shows the number of books available for borrowing.
- **Borrowed Books:** Shows the number of books currently borrowed by members.
- **Overdue Books:** Shows books that have passed their return dates.
- **Total Members:** Shows the total number of registered library members.
- **Active Members:** Shows members who are allowed to borrow books.
- **Suspended Members:** Shows members who are temporarily not allowed to borrow books.
- **Returned Books:** Shows the number of books that have been returned.

### Purpose of the Statistics Report

The statistics report will help the librarian monitor book availability, track borrowing activities, identify overdue books and understand membership records.

The report will also support better decision-making and improve the management of library resources.

*Note: The statistics and reports section is a planned system enhancement and will be implemented in the application.*
